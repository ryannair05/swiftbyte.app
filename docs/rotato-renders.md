# Rotato artwork

The website uses four optimized full-device WebP renders under `assets/renders/`: halls, dining, nutrition, and CATA. All four are referenced by the homepage. They were rendered with the Rotato CLI using an iPhone 16 device and cropped to preserve the full phone.

Source scene originally supplied at `/Users/ryannair/Documents/Meet and Eat.rotato`. Unused local scene copies, full PNG exports, screenshots, and intermediate videos have been removed from this repository.
